feat: Add DataService with builder pattern for simplified TM1 data operations

This commit introduces a new DataService that provides a fluent, builder-pattern
interface for TM1 data operations, simplifying the existing CellService API.

## New Features

### Core DataService Infrastructure
- DataService entry point with tm1.data accessor
- Mixin-based architecture for code reuse:
  - SandboxMixin: Sandbox context support
  - FilterMixin: Cell filtering (skip_zeros, skip_consolidated, skip_rule_derived)
  - PerformanceMixin: Performance options (use_blob, use_compact_json, use_iterative_json)
  - PaginationMixin: Result pagination (top, skip)
  - AsyncMixin: Parallel execution (max_workers, async_axis)
  - AttributeMixin: Attribute handling
  - WriteMixin: Write operation options

### Query Executors
1. QueryExecutor (MDX queries)
   - Accepts MDX strings or MdxBuilder objects
   - 8 terminal operations: as_dict(), as_dataframe(), as_csv(), as_values(),
     as_pivot(), count(), as_raw(), as_cellset_id()
   - Full mixin support for all options

2. ViewQueryExecutor (Cube views)
   - Execute native and MDX views
   - 7 terminal operations: as_dict(), as_dataframe(), as_csv(), as_values(),
     count(), as_raw(), as_cellset_id()
   - Support for private views

3. CoordinateQueryExecutor (Direct cell access)
   - Read single or multiple cell values
   - 2 terminal operations: as_value(), as_values()
   - Smart coordinate detection

### Test Infrastructure
- TM1pyTestCase: Shared base class for test infrastructure
  - Provides test cubes, dimensions, views, and data
  - Automatic setup/teardown without inheriting test methods
  - Enables fast, isolated test execution

## Usage Examples

MDX query with options:
  df = tm1.data.mdx(query).skip_zeros().sandbox('dev').as_dataframe()

View query with chaining:
  result = tm1.data.view('Sales', 'Budget').skip_consolidated().top(100).as_dict()

Direct cell access:
  value = tm1.data.coordinates('Sales', ('2024', 'Jan', 'Actual')).as_value()

Performance optimization:
  csv = tm1.data.view('Sales', 'Budget').use_blob().as_csv()

Async execution:
  df = tm1.data.mdx(query).max_workers(8).as_dataframe()
